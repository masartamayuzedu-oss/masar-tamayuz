# مسار التميز — منصة الخدمات الطلابية والأكاديمية

موقع ثابت مبني بواجهات HTML وCSS وJavaScript، ويستخدم Supabase لخدمات المصادقة وقاعدة البيانات والتخزين.

## الملفات

- `index.html`: الصفحة الرئيسية ولوحة إدارة المحتوى.
- `من-نحن.html`: صفحة التعريف بالمنصة.
- `server.js`: خادم ملفات ثابتة بديل (لا يستخدمه أمر التشغيل الافتراضي حالياً).
- `package.json`: إعداد تشغيل الموقع باستخدام الحزمة `serve`.

## التشغيل المحلي

```bash
npm install
npm start
```

يستخدم أمر التشغيل الافتراضي الحزمة `serve` لعرض ملفات المجلد الحالي. يجب أن تكون قيمة `PORT` متاحة في بيئة التشغيل؛ ويستخدم Render عادةً متغير المنفذ الذي يمرره تلقائياً.

## النشر على Render

- نوع الخدمة: Web Service.
- Build Command: `npm install`.
- Start Command: `npm start`.
- Root Directory: المجلد الذي يحتوي مباشرة على `package.json` و`index.html`.

## Supabase

يحتوي كود المتصفح على Project URL وPublishable Key. مفتاح `sb_publishable_` مخصص للاستخدام العام في المتصفح، ولا يجوز وضع `service_role` أو أي مفتاح سري في ملفات الواجهة.

تستخدم الصفحة الرئيسية الجداول التالية بحسب الاستدعاءات الموجودة في الكود:

- `services`
- `offers`
- `portfolio_items`
- `platform_settings`
- `admin_users`
- `site_headings_config`

كما تستخدم التخزين `masar-media` و`masar-private-media`. يجب ضبط سياسات RLS وسياسات Storage في مشروع Supabase بما يتوافق مع صلاحيات القراءة العامة وعمليات المشرف.

### الوسائط الخاصة

عرض ملفات الفيديو وPDF الخاصة يستدعي Edge Function باسم `get-media-view-url` على المسار `/functions/v1/get-media-view-url`. هذه الوظيفة ليست ضمن هذا المستودع، ويجب أن تكون منشورة في مشروع Supabase وأن تتحقق من صلاحية الوصول قبل إصدار Signed URL.

## ملاحظات أمنية وتشغيلية

- لا تضع مفاتيح سرية في ملفات HTML أو JavaScript.
- لا تعتبر وجود واجهة دخول بديلاً عن سياسات RLS والتحقق من صلاحيات المشرف في قاعدة البيانات.
- احتفظ بنسخة احتياطية من قاعدة البيانات والتخزين قبل أي تعديل بنيوي.
- اختبر تسجيل الدخول، وقراءة البيانات، ورفع/حذف الوسائط بعد كل نشر.


## تحديثات إدارة أيقونات الخدمات والرفع

- سجل أيقونات الخدمات يُحفظ في جدول `site_headings_config` تحت المفتاح `service-icon-registry-v1`؛ لا يتطلب إنشاء جدول جديد.
- يجب أن تسمح سياسات RLS للمشرف المصرح له بقراءة وإضافة وتحديث سجل الأيقونات.
- عند تغيير اسم/رمز أيقونة مستخدمة، يحاول التطبيق تحديث عمود `services.icon` للخدمات المرتبطة بها.
- تقدم الرفع يظهر في لوحة ثابتة خارج لوحة الإدارة، لذلك يظل مرئياً عند التبديل بين عرض المشرف وعرض الزوار داخل الصفحة نفسها.
- لا يمكن للمتصفح ضمان استمرار نقل ملف كبير بعد إغلاق التبويب أو إيقاف المتصفح/النظام. تم إضافة تنبيه قبل مغادرة الصفحة أثناء الرفع. استئناف الرفع بعد إغلاق المتصفح يحتاج تخزين ملف الرفع محلياً (IndexedDB) أو خدمة رفع خلفية مستقلة.
